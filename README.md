# PATHTREES Reference Implementation

> **Attribution note:** This repository is retained as reference material used during the `math-deep-structure-research` project. PATHTREES is **not presented here as my original standalone software project**.

The code and documentation in this repository were used to study computational approaches for constructing, visualizing, and exploring continuous tree landscapes in Billera-Holmes-Vogtmann (BHV) tree space.

The original implementation and figures referenced in this repository are associated with the PATHTREES project and external contributors. This copy is kept for research reference and methodological study.

## How This Was Used

Within the broader Math Department Deep Structure research project, PATHTREES served as a methodological reference for understanding geometric and computational techniques in tree space. Our research work extended beyond this reference implementation and included independent work in clustering, spectral methods, and barycenter-based analysis.

Main research repository:

- [Math Deep Structure Research](https://github.com/ziqixu22/math-deep-structure-research)

## Reference Functionality

PATHTREES supports tasks such as:

- constructing paths between trees in BHV tree space
- exploring convex-hull structure for collections of trees
- computing geodesic or Robinson-Foulds-based distances
- multidimensional scaling visualization
- branch-length optimization
- iterative refinement and validation
